# 섭취 저장 완료 요약

저장 완료 메시지에 최종 제안의 날짜·끼니, 음식별 적용 g와 칼로리, 합계 칼로리를 표시한다. 수정·제외 후 확정한 제안을 사용하며 원래 입력 문장에서 다시 추정하지 않는다. 직접 결정 API의 응답 payload를 우선하고, 채팅 확정 경로도 resolve 완료 payload로 요약한다. 취소·저장 실패는 성공 요약을 표시하지 않는다.

표시 예시:

> 섭취 기록을 저장했습니다.
>
> 2026-10-16 · 아침
>
> - 계란후라이 · 200g · 400 kcal
> - 제육볶음 · 300g · 600 kcal
>
> 합계 1000 kcal

검증: 프론트 저장 성공·실패 및 순수 요약 테스트 12개, 백엔드 제안 흐름 통합 테스트 9개, 프로덕션 빌드 통과. 예시 수치는 화면 형식 설명용이며 새 영양값이나 성능 실험 결과가 아니다. 운영 계정에 검증 식사를 추가하지 않았다.
