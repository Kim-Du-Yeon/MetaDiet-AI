# 저장 전 확인 카드의 음식별 수정·제외

2026-10-19 구현. 공개 배포·실제 브라우저 검증은 아직 수행하지 않았다.

## 원인과 변경

기존 카드는 모든 음식에 식품 ID가 있고 사용자 영양표 음식이 없어야 수정 UI를 표시했다. 한 항목만 조건을 충족하지 않아도 카드 전체의 수정·제외 기능이 숨겨졌다.

음식별 분량 입력과 제외 버튼을 모든 수정 가능한 확인 카드에 표시한다. DB 음식은 기존 DB 조회로 영양값을 재계산한다. 사용자 영양표와 식품 ID 없는 기존 항목은 서버가 보관한 제안의 영양값을 g 비율로 환산한다. 새로운 영양값을 추측하거나 공용 DB에 등록하지 않는다. 해당 항목의 수정 단위는 g다.

분량 수정 또는 제외 후에는 ‘수정한 분량 다시 계산’을 눌러 새 제안을 받아야 확정할 수 있다. 계산 전 합계가 이전 값임을 안내한다. 전체 제외는 취소로 안내하고 저장을 차단한다. 저장 전 제외는 이미 확정된 기록의 영구 삭제와 다르다.

소유권·제안 버전·대화 잠금·확정 전 섭취 기록 미변경 구조를 유지한다.

- 최초 Jest 실행은 sandbox 임시 폴더 realpath EPERM으로 실패했다. 권한이 허용된 실행 환경에서 동일 명령을 재실행해 통과했다.
