# v1 통과·v2 실패 원문 사례

과거 Pro 판정과 답변은 변경하지 않았다. 아래 점심 판정 두 건은 평가 입력 누락 가능성을 별도로 표시한다.

## cb2-eval-missing_choices-09

기존 v2 판정 이유: Answer A fails to ask for the missing options and instead invents two new options to replace them, violating the requirement to ask for the missing fields.

### v1

이전에 말씀해주신 두 가지 선택지 정보가 대화에 남아있지 않아 어떤 메뉴인지 바로 확인하기 어렵습니다.

현재 목표 2,070kcal 중 825kcal를 섭취하셔서 약 1,245kcal의 여유가 있으므로, 두 선택지 중 단백질과 채소가 비교적 충분하고 든든하게 구성된 식단을 고르시는 것을 추천합니다. 생각하고 계신 두 가지 메뉴를 짧게 알려주시면 목표에 맞춰 더 알맞은 쪽으로 골라드리겠습니다.

### v2

현재 이전 대화 기록에서 이전에 언급된 두 가지 메뉴의 구체적인 명칭이 남아있지 않아 정확한 메뉴를 바로 불러오기 어렵습니다.

남은 하루 목표 칼로리(약 1,245kcal)와 균형을 고려해 단백질과 채소를 곁들일 수 있는 두 가지 대체 메뉴로 **두부채소덮밥**과 **닭가슴살 샐러드 파스타**를 추천드립니다. 이 중에서 선호하시는 식사가 있으시다면 말씀해 주세요.

## cb2-eval-missing_portion-09

기존 v2 판정 이유: Correctly asks for the missing portion size, but includes an unnecessary request regarding UI buttons (기입하기/제외하기).

### v1

사용자가 섭취한 달걀밥의 구체적인 양(밥의 분량, 달걀 개수, 사용한 유지류 등)을 알지 못하고 기본 1인분 추정값 사용도 배제하길 요청하셨으므로, 현재로서는 정확한 총 칼로리를 계산할 수 없습니다.

섭취하신 밥의 대략적인 양(예: 공기 기준 또는 g)과 달걀 수, 참기름·버터 등의 추가 여부를 알려주시면 확인 후 정확한 영양 성분을 계산해 드리겠습니다.

### v2

달걀밥의 기본 1인분 추정을 사용하지 않고 실제 칼로리를 정확히 계산하려면, 드신 밥의 양(g 또는 공기 기준)과 달걀 개수, 사용한 기름(참기름·들기름·버터 등)이나 양념의 양 정보가 필요합니다.

현재는 섭취량 정보가 없어 정확한 계산을 보류하며, 대략적인 분량을 알려주시면 그에 맞춰 계산해 드리겠습니다. 기록을 진행하시려면 화면의 기입하기 또는 제외하기를 선택해 주세요.

## cb2-eval-known_intake-08

기존 v2 판정 이유: Answer B incorrectly assumes and states that the 814kcal already consumed was specifically for lunch, which is an invented fact not supported by the context.

### v1

네, 샌드위치로 드셔도 괜찮습니다.

현재 목표 칼로리(2,122kcal) 대비 섭취 여유가 있으므로, 닭가슴살·달걀·참치 등 단백질 재료와 신선한 채소가 풍부하게 들어간 구성을 선택해 보세요. 마요네즈나 달콤한 소스 비중을 줄이고 호밀빵이나 통곡물빵을 활용하면 다이어트 중에도 균형 잡힌 든든한 식사가 됩니다. 탄산음료 대신 물이나 달지 않은 차를 곁들이시면 더욱 좋습니다.

### v2

네, 샌드위치로 식사하셔도 괜찮습니다.

현재 하루 목표 칼로리가 2,122kcal이고 점심 식사로 814kcal를 섭취하신 상태이므로, 남은 식사에서 가벼운 샌드위치를 선택하는 것은 좋은 방법입니다. 식단을 관리하실 때는 닭가슴살, 달걀, 참치 등 단백질 재료와 양상추나 토마토 같은 채소가 풍부하게 들어간 제품을 고르시는 것을 권장합니다. 마요네즈나 달콤한 소스가 많은 종류는 열량이 높아질 수 있으니, 소스가 적거나 담백한 통밀 샌드위치를 선택하시면 더욱 균형 있게 즐기실 수 있습니다.

**해석 주의:** 실제 공통 DB fixture에는 해당 점심 열량 행이 있다. 기존 judge가 합계만 받았으므로 이 두 건을 확정적인 모델 환각으로 단정하지 않는다.

## cb2-eval-unlogged_meal-03

기존 v2 판정 이유: Answer A incorrectly assumes the 499 calories were consumed for lunch, which is an invented fact not supported by the context.

### v1

네, 샌드위치를 드셔도 괜찮습니다.

현재 하루 목표 칼로리가 1877kcal이므로, 샌드위치를 고르실 때는 닭가슴살, 달걀, 참치 등 단백질 재료와 신선한 채소가 충분히 들어간 구성을 선택해 보세요. 마요네즈나 달콤한 드레싱 대신 올리브오일이나 머스터드 소스를 가볍게 곁들이면 다이어트 목표를 유지하면서 든든한 한 끼를 챙기실 수 있습니다.

### v2

네, 샌드위치를 드셔도 괜찮습니다.

현재 하루 목표 칼로리가 1877kcal이고 점심으로 499kcal를 섭취한 상태이므로, 남은 열량 내에서 충분히 조절해 드실 수 있습니다. 다만 다이어트 목표를 고려해 튀긴 패티나 마요네즈류 소스가 많은 종류보다는 닭가슴살, 달걀, 로스트비프 등 담백한 단백질과 채소가 풍부한 통밀 샌드위치를 선택하는 것을 권장합니다.

**해석 주의:** 실제 공통 DB fixture에는 해당 점심 열량 행이 있다. 기존 judge가 합계만 받았으므로 이 두 건을 확정적인 모델 환각으로 단정하지 않는다.

## cb2-eval-missing_choices-05

기존 v2 판정 이유: Answer A invents two options instead of asking the user what the missing options were, violating the requirement to ask for the missing comparison options.

### v1

현재 대화 기록에 이전에 말씀해주신 두 가지 메뉴 정보가 남아있지 않아 확인이 어렵습니다.

닭가슴살 샐러드 외에 고민 중이셨던 두 가지 메뉴 이름을 알려주시면, 오늘 현재 섭취 상황(목표 1,950kcal 중 725kcal 섭취)에 맞춰 더 적합한 메뉴를 바로 비교해 드릴게요.

### v2

이전에 언급된 메뉴 정보가 남아있지 않으므로, 남은 목표 칼로리(약 1,225kcal)와 균형을 고려하여 선택하실 수 있는 두 가지 식사 옵션을 제안해 드립니다.

1. **소고기 구이와 쌈채소 정식 (약 500~600kcal)**: 기름기가 적은 부위(우둔살, 안심 등) 150g에 밥 반 공기(100g), 풍성한 쌈채소를 곁들이는 구성입니다.
2. **연어 구이 덮밥 (약 550~650kcal)**: 구운 연어 1토막(120g)에 밥 2/3공기, 양파절임과 어린잎 채소를 곁들여 양질의 지방과 단백질을 챙기는 구성입니다.

두 메뉴 중 선호하는 방향을 선택해 주시면 식단 기록 및 세부 조율을 도와드리겠습니다.

## cb2-eval-missing_choices-10

기존 v2 판정 이유: Answer B fails to ask for the specific missing options, instead asking for general meal preferences or keywords, which does not fulfill the required field.

### v1

이전 대화에서 나눈 두 가지 선택지의 구체적인 정보가 현재 남아 있지 않아 바로 특정하여 골라드리기 어렵습니다.

생각해 두셨던 두 가지 메뉴의 이름을 간단히 알려주시면, 오늘 현재 섭취 상황(약 850kcal 섭취, 목표 2,100kcal)에 맞춰 더 적합한 식사를 바로 비교하고 추천해 드리겠습니다.

### v2

이전에 안내해 드렸던 두 가지 옵션 정보가 현재 대화 내역에 남아있지 않아 바로 특정하여 골라드리기 어렵습니다.

원하시는 식사 방향(예: 단백질 위주, 간편식 등)이나 떠오르는 메뉴 키워드를 살짝 알려주시면, 오늘 목표 칼로리(목표 2,100kcal / 현재 섭취 850kcal)에 맞춰 알맞은 식단으로 제안해 드리겠습니다. 편하게 말씀해 주세요!
