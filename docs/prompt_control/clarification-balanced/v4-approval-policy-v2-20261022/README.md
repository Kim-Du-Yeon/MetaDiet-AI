# v4 승인 정책 v2: 기존 증거 재검토

기존 결과를 본 뒤 사용자의 명시적 요청으로 정책을 개정한다. 새 사전등록 성능 실험이 아니다. 원래100쌍 원본·거부 판정·이전 정책은 변경하지 않는다. 후보 자체의 기존 품질·안전·최신값·속도·비용 한계는 유지하고, 기준선의 정상완료 의무만 실패 포함100시도 정산·채점 의무로 분리한다.

policy.json은 새 승인 판정과 추가 호출 전에 고정했다. 모든 기준선 실패는 원래100분모에 남는다. 200개 생성·100쌍 Pro 채점·원장을 재사용하며 신규 품질 채점0회다. Staging 실제 채널로 읽은 서명 릴리스의 합성 읽기 전용 동작을 최대6건, 이후 공개 브라우저에서 실제 운영 커밋과 상담을 확인한다. 예상 추가 사용량 비용 $0.01–0.10이며 새 가입·요금제 변경은 없다. 이 점검은 성능 비교가 아니다. 실제 사용자 A/B는 계속 꺼 둔다.
