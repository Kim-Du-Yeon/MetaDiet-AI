# $5 제한 검증: 채점 예약 한도로 중단

2026-10-21. 전체 $5와 단계별 상한을 유지한 실제 실행 기록이다. 운영 데이터/DB/인덱스를 수정하지 않았다.

| 단계 | 결과 | 장부 사용·예약액 USD |
|---|---|---:|
| 최소 연결 | Lite·Flash·Pro 각 1회 응답 수신 | 0.000949 |
| 개발 확인 | 기존 사례 3개 × 2조건. 충분성 기준 기존 1/3, 개선 3/3 | 0.014726 |
| 본 비교 | 기존 7건·개선 7건 응답 저장 후 중단 | 0.083819 |
| Pro 최종 채점 | 제출하지 않음 | 0 |
| 합계 | 중단 상태를 장부에 영속화 | **0.099494** |

장부 합계는 공급자 청구서가 아니다. 종료 시 진행 중이던 전송 예약 2건 $0.0191을 포함한다.
확인되지 않은 비용을 무료로 처리하거나 예약을 지우지 않았다.

## 중단 이유

기존 저장된 100쌍을 같은 Pro Batch 설정(최대 출력 2,048)으로 보내는 계획의 보수적 예약액은
약 $2.302544다. 이는 **실제 청구 예상 확정액이 아니라 최대 사용량 예약 추정**이며,
채점 단계 $1 상한을 넘으므로 장부가 `Budget exhausted: judge`로 캠페인을 중단했다.
실제 Batch 제출/추가 Pro 채점은 없었다. 총 $5를 소진한 것도 아니다.

본 생성과 병행해 이 사전 계산을 하면서 14개 응답이 생성됐다. 이 검사는 생성보다 먼저
했어야 했다. 수정 후에는 본 비교 실행기가 생성 전에 Pro Batch 출력량 예약만으로도
계획이 불가능한지 확인한다. 100 × 2,048 × $12/백만 × 50% = **$1.2288**로,
입력량을 제외해도 현재 채점 한도를 넘는다. 상한을 자동으로 올리거나 출력 제한을 낮추지 않는다.

## 저장 자료 재사용과 결과 해석

- 기존 개발 Pro 평가 40건과 과거 응답/검색 문맥은 그대로 보존했다. 재생성·재채점하지 않았다.
- 새 `attempts.jsonl`의 14개 응답과 문맥도 향후 채점 입력으로 재사용할 수 있다.
- 계획은 200시도지만 기록은 14건이다. 나머지 186슬롯에는 종료 당시 진행 중이던 최대 3개
  시도가 포함되므로 모두 미시작으로 표현하지 않는다.
- 조건별 100건 기준 미충족이며 최종 품질은 미평가다. 부분 응답의 지연·근거 적중률로
  성능 개선, 품질 비열등성, 배포 통과를 주장하지 않는다. 배포/브라우저 검증은 진행하지 않았다.
- 서로 다른 실행 조건의 이전/현재 응답을 합쳐 100건 결과로 만들지 않는다.

## 수정·오프라인 확인

구조화 출력용 함수 스키마가 외부 유료 도구와 함께 차단되는 문제를 유료 개발 실행 전에
오프라인으로 재현·수정했다. 함수 선언 스키마는 입력 토큰 예약에 포함하고, Google Search
등 추가 요금 도구는 계속 차단한다. [공식 함수 호출 문서](https://ai.google.dev/gemini-api/docs/function-calling).
생성 전 채점 가능성 검사까지 포함한 관련 테스트 **72개 통과**. 중단 후 추가 유료 호출 없음.

## 남은 작업

현재의 일괄 Batch 예약 정책으로는 $1 안에 100쌍 채점을 제출할 수 없다. 같은 예산을 유지하려면
작은 Batch 분할 제출과 완료 후 원시 사용량 정산·예약 해제 경로를 먼저 오프라인에서 검증해야 한다.
분할하더라도 실제 누적 비용이 $1에 닿으면 중단해야 하며 완료를 보장하지 않는다.
이 정책 변경과 새 비용 계산 전에는 중단 장부를 초기화하거나 유료 실험을 자동 재개하지 않는다.
