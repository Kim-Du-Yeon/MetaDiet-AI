# v13 동일 100사례 최종 비교

동결 사례 100시도(고유 질문 40개 반복)에 기존 v9 답변·역사적 채점 100개를 재사용한다. 동일 v13 소스·모델로 완료된 ag-000 최소 실측도 재생성 없이 한 번 재사용했다. 새로운 paired payload의 Pro 판정은 새로 받으며, 과거 판정을 새 후보 판정으로 대신하지 않는다.

첫 분할 ag-000~004는 답변 생성까지 5건 완료했다. 그중 새 생성은 4건이다. `packet-0000.json`은 5쌍의 native Pro Batch와 예약/실제 정산을 추적한다. 이 채점의 통과 여부를 확인하기 전 다음 생성 분할을 실행하지 않는다. 개별 행 `correct:false`는 deferred judge 기본값이며 품질 판정이 아니다.

전체 $5와 단계별 probe $0.05 / development $0.05 / comparison $1.70 / judge $3.10 / browser $0.10을 유지한다. 기존 미정산 예약을 환급하거나 장부를 초기화하지 않는다. 실패·불완전 사용량·예산 거부·후보 오답/비충실 판정이면 추가 유료 실행 없이 중단한다.

기존 역사적 지연은 worker3, 새 실행은 즉시 중단을 위한 worker1이므로 인과적 속도 개선을 주장하지 않는다. 실패·타임아웃은 완료 시도 분모에 유지하고, 미실행 슬롯은 별도로 표시한다. 전체 성능 증거는 100시도씩 완료한 경우만 제시한다. 실제 사용자 결과가 아닌 반복 개발 질문 평가다.

상태 및 최종 판정은 완료 후 별도 결과에 기록한다. 전체 기준 미통과 상태에서 배포·운영 브라우저 검증·GitHub 반영을 하지 않는다.

## 최종 결과: 15건 후 품질 실패로 중단

첫 두 분할 10건은 후보 정답/충실성 판정을 통과했다. 세 번째 분할의 `ag-013`이 정답 판정에 실패해 즉시 중단했다. 15건 생성 완료(이 중 기존 v13 답변 1건 재사용, 새 생성 14건), 85건 미실행이다. 기존 v9 답변·역사적 채점 100개를 보존하고 실제 비교 채점은 15쌍만 새로 수행했다. 완료된 15쌍에서 기존/후보 모두 정답 14건, 후보 충실성 15건이다. 이는 조기 중단된 개발 사례의 중간 집계이며 100건 정답률·성능 개선으로 주장하지 않는다.

실패 질문은 ISSN의 1회 단백질 섭취 권고와 개인별 적용 조건이다. 후보가 핵심 수치 및 조건을 답하지 못했다. Pro는 답변이 제공 문맥에는 충실하지만 정답을 보류해 incorrect/faithful로 판정했다. 저장 상태에는 `rounds=1`, `stop_reason=duplicate_query`, `answer_coverage=partial`, 미해결 핵심 수치/조건이 남아 있다. 즉 조각난 근거와 중복 질의 종료가 남은 문제이며 원문 연결 실패의 재발은 아니다. 판정 원문과 실제 답변은 `ag013-review.json`, 전체 완료 채점은 `paired-judges-completed15.jsonl`에 보존했다. 이 코호트에서 추가 수정·재호출을 하지 않았다.

Pro Batch 3개 모두 완료·실제 사용량 정산, 새 pending Batch 0개. 이번 증분 $0.172376, 누적 사용·예약 **$2.256519/$5**다. 단계별 사용액: comparison $1.445529/$1.70, judge $0.784683/$3.10, development $0.025021/$0.05, probe $0.001286/$0.05, browser $0/$0.10. 이전 미정산 예약 $0.019100은 그대로 유지했다. 총 한도나 단계별 예산 때문에 중단한 것은 아니다.

전체100건 비교 **미완료·미통과**로 배포·브라우저 검증·GitHub push는 수행하지 않았다. 원시 집계 `final-result.json`과 추가 호출 금지를 표시한 `experiment-stop.json`을 남겼다. 현재 운영 버전 유지.
