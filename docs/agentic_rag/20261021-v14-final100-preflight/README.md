## 예산 사전 확인

기존 누적 사용·예약 $2.270037/$5, comparison 사용 $1.453787/$1.70으로 잔여 $0.246213이다. 동결한 Flash 답변 출력 상한2048·기존 가격표 $3.75/백만 출력 토큰을 적용하면 100건 출력 상한 예산만 $0.768이다. 잔여액보다 $0.521787 크고, 입력/controller/번역/임베딩 비용은 포함하지 않은 값이다.

이는 실제 최소 비용이나 청구액 예측이 아니다. 짧은 출력과 실제 정산에 따라 실제 비용은 낮을 수 있지만, 현재 상한으로 전체 계획에 필요한 보수적 예산을 확보할 수 없다는 의미다. 한 분할이 예약 가능하다는 사실만으로 최종100건을 끝낼 수 있다고 판단하지 않았다. 새 답변의 payload가 달라지는 채점은 기존 판정을 가져다 쓸 수 없다.

이전 재배분은 채점 예산을 확보했으나 새100건 전체의 생성 단계 상한을 확보하지 못했다. 단계별 상한 유지 요청에 따라 예산을 다시 옮기거나 출력/평가 조건을 낮추지 않았다.

**신규 유료 호출0, 장부 SHA 확인 전후 동일, 새 pending Batch0.** 전체100건 비교 미실행·미통과로 배포/운영 브라우저 검증/GitHub push를 하지 않았다. 기존 단일 사례 수정 성공을 전체 품질 성과로 확대하지 않는다.
