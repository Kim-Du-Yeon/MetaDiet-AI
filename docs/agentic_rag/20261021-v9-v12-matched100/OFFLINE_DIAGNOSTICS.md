# 원문 발췌 검증 진단 보강 (오프라인)

기존 ag-000 실패에는 발췌·원문 쌍이 없어 세부 원인을 소급 확정할 수 없다. 과거 행과 동결 소스는 수정하지 않았다.

후속 구현은 `agentic.excerpt_failures`와 `rag_excerpt_verification` 구조화 로그에 발췌 번호, 비교한 문서 번호, 원문/발췌 길이, 실패 유형과 위치를 남긴다. 검증 실패로 문맥이 제거되어도 진단은 보존된다. 로그에는 질문·발췌·원문·출처 경로·자격 정보를 넣지 않는다.

- `empty_excerpt`: 공백 제거 후 빈 문자열.
- `numeric_boundary_or_token_mismatch`: 공백 제거 문자열은 있지만 숫자 경계 또는 숫자 토큰이 달라 거부.
- `text_mismatch`: 공백 제거 후에도 일치하지 않음. 최대 128자의 공통 접두부 후보와 원래 문자열의 다음 비교 위치를 기록한다. 후보는 정답 위치나 문장 재작성의 증명이 아니다. 접두부 한도 도달 시 그 이후 원인은 알 수 없다.

공백만 허용하는 기존 수용 규칙은 유지했다. 문장부호·수치 변경·의역·여러 문서에 걸친 발췌를 자동 수용하지 않는다. 저장된 ag-022 결과를 오프라인으로 재사용해 공백 차이 허용이 유지됨을 검사하고, 합성 테스트로 수치 변경·부분 숫자·문맥 제거 후 로그 보존·내용 비노출을 검사한다. 실제 ag-000 원인을 재현했다고 주장하지 않는다.
