# ag-013 불완전 문맥·중복 질의 종료 수정

## 저장 자료로 확인한 원인

이전 결과는 1회 단백질 권고가 잘린 인접 청크 앞 700자까지만 제공했다. 신뢰된 로컬 코퍼스의 동일 청크는 1,135자로, 잘린 부분 뒤에 핵심 수치와 연령/최근 저항 운동 조건이 실제로 있었다. 한국어 질문과 영어 문서의 직접 문자열 일치가 없어 기존 700자 창이 앞부분으로 선택되었다. 앞선 긴 검색 결과들이 6000자 문맥을 먼저 차지한 것도 이어지는 근거를 담기 어렵게 했다. controller가 미해결 조건을 반환하면서 질의를 바꾸지 않아 `duplicate_query`로 첫 라운드에서 종료했다.

## 수정 v14

- 인접 청크는 최대1200자의 연속 원문으로 보존한다. 정상 길이의 청크는 온전히 포함하고 큰 과거 청크만 제한 창을 쓴다. 수치/문장을 생성하지 않는다.
- 문맥은 최상위 검색 결과를 먼저 두고 인접 근거를 우선 배치한 뒤 나머지를 담는다. 최대8문서·6000자 상한을 유지한다. 상한 때문에 모든 원본 문서를 온전히 보존한다는 보장은 없다.
- 재작성 질의가 비었거나 중복이고 미해결 조건이 있으면 원래 질문+미해결 조건으로 결정적 대체 질의를 만든다. 골드 답안·고정 수치·영양 키워드를 코드에 추가하지 않았으며 추가 controller 호출 없이 기존 최대2라운드 안에서만 사용한다. 미해결 조건도 없거나 대체 질의도 중복이면 중단한다.
- 문서ID 기반 원문 연결·점수 게이트·정의 충분성·부분 답변·비용 가드를 유지했다.

별도 합성 질문과 저장 ag-013으로 오프라인 회귀를 만들었다. 실제 코퍼스 원문 위치/내용 일치, 숫자와 적용 조건의 문맥 포함, 중복 질의가 미해결 조건으로 단 한 번 바뀌는 경로를 검사했다. 개발에 사용한 사례이므로 독립 최종 성능 근거가 아니다.
