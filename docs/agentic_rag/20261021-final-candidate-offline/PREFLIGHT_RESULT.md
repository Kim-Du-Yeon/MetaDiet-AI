# 최종 비교 예산 사전 확인: 유료 호출 전 중단

고정 후보·저장 결과 해시와 비용 장부를 읽기 전용으로 확인했다. 전체 잔여액은 $2.922732이지만 채점 단계 잔여액은 $0.290868이다. 기존 사용·예약 $2.077268, 단계별 한도와 미정산 예약을 모두 유지했다.

동결한 paired Pro 채점은 사례당 출력 상한 2048, Native Batch 가격 계수 0.5, 100쌍이다. 코드에 고정된 가격표의 출력 단가 $12/백만 토큰을 적용한 **출력 상한 예산만 $1.228800**으로 채점 잔여액보다 $0.937932 크다. 입력 비용은 포함하지 않았다. 이는 실제 지출 예측이나 최소 청구액이 아니다. 실제 출력은 더 짧을 수 있으나, 결과를 받기 전에 100건 완료에 필요한 보수적 예산을 확보할 수 없다는 판단이다. 새 유료 요청을 하지 않아 모델 할당량·결제 상태도 실시간 확인하지 않았다.

기존 `preflight_batch_judge`는 한 분할의 출력 상한만 검사하므로 통과하더라도 전체 완료 가능성을 보장하지 않는다. 이번에는 전체 100건 계획의 출력 상한을 별도로 검사해 생성 전에 중단했다. 분할마다 실제 사용량 정산으로 계속 진행할 가능성에 기대어 먼저 비용을 쓰지 않았다.

기존 v9 채점은 감사 자료로 재사용할 수 있지만 새 후보 답변이 포함된 paired payload의 채점은 재사용할 수 없다. 이미 실패한 과거 1건도 새 후보 성공 결과로 대체하지 않는다.

**신규 유료 호출 0건. 실패 사례 재확인·100건 생성·채점·배포·브라우저 검증·GitHub push 없음.** 장부 SHA가 확인 전후 동일하다. 원시 계산은 `final-comparison-preflight.json`에 보존했다.

현 조건에서는 여기서 종료한다. 추후 진행하려면 채점 단계 예산 변경 또는 평가 모델/출력 상한/채점 설계 변경을 별도 결정해야 한다. 이번에는 한도 이동·모델 교체·출력 축소로 기존 평가 조건을 바꾸지 않았다. 현재 운영 버전은 유지한다.
