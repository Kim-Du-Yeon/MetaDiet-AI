- 변경 전후, 적용 집단, 단위, 예외를 답변 단계에 항목별 근거로 넘기는 계약이 없었다.

## 수정

controller-v10은 최대 4개·각 240자 원문 발췌를 반환한다. 실제 평가한 문서 본문에 정확히 존재하는 발췌만 답변 계약에 넣는다. 기본 출력 한도 512토큰, 근거 6000자, 최대 2회 검색, 35초 제한은 유지했다. 계약에는 complete/partial/none과 미해결 항목을 구분한다.

부족한 필수 항목은 여전히 재검색한다. 정상적인 검색 종료 후에도 부족한 항목이 있고 검증된 발췌가 있을 때만 부분 답변을 허용한다. 검색·평가 오류, 시간 초과, 낮은 유사도, 본문에 없는 발췌는 기존처럼 차단한다. 답변에는 확인된 사실과 적용 조건을 먼저 제공하고 미확인 항목만 보류하도록 전달한다. team 도구와 QA 양쪽에서 기존 answer_guidance 경로를 재사용한다.

## 별도 개발셋과 한계

`backend/tests/unit/test_agentic_partial_development.py`의 가상 지표·가상 문서 사례는 기존 평가 질문이나 영양 정답을 복제하지 않았다. 원문 발췌 보존, 부분 답변 계약, 허위 발췌 차단, 낮은 점수 차단, 재검색 오류/시간 초과 차단, 한국어 표와 적용 범위·변경 전후·하한 조건 보존을 오프라인 mock으로 확인한다. 기존 테스트 삭제·skip 추가 없음.

이 테스트는 모델이 실제로 조건을 빠뜨리지 않는다는 품질 증명이 아니다. 원문 포함 검사는 발췌의 실재만 검증하며 의미적 적절성은 보장하지 않는다. 512토큰 내 새 구조 출력 성공률, 전체 보류 감소, 최종 답변의 조건 준수는 아직 실측하지 않았다. 완전한 필수 조건 누락 자동 검출이나 의미 검증은 구현하지 않았다. 맥락 6000자 배치와 답변 잘림도 추가 관찰 대상이다. 과거 실측 85%→83% 결과는 유효하며 개선 성공으로 바꾸지 않는다.
