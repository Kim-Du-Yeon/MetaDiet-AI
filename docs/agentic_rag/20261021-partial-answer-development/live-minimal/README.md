# 최소 유료 검증 결과 — 복잡한 근거에서 구조 검증 실패로 중단

2026-10-21. 전체 $5와 기존 단계별 예산·누적 사용액을 유지했다. 운영 배포·사용자 DB 변경 없음.

| 단계 | 결과 | 추가 생성/채점 |
|---|---|---|
| 새 controller-v10 구조 | 가상 문서에서 supported_excerpts·missing_core 구분, 원문 일치 통과 | Lite 1회 |
| 작은 별도 개발셋 | 부분 답변·재검색 수치·임상 범위·한국어 표 4건 흐름/답변 생성 통과 | 4답변, probe의 첫 판정 재사용 |
| 일반 Pro 채점 | 429, daily quota로 분류; 반복 호출하지 않음 | 실패 1회, 사용량 불명 예약 보수적으로 유지 |
| Pro Batch 채점 | 위 4답변 correct/faithful 모두 통과, 실제 사용량 정산 완료 | 4개 내부 요청, 실제 합계 $0.006294 |

| 저장된 실제 실패 문맥 재생 | 첫 사례 ag-022의 평가 출력 유효성 검사 실패로 중단 | 평가 1회; 답변 생성·나머지 3사례·추가 채점 없음 |

가상 개발 사례 4건 결과는 성능 비교나 실제 RAG 정확도 수치로 일반화하지 않는다. 실제 실패 문맥 재생은 저장된 후보 문서만 사용하며 검색·임베딩을 다시 하지 않았다. 단일 회차의 고정 근거 검사로, 운영 재검색 루프의 종단 검증이 아니다. max_score=0은 새 검색 점수가 없음을 나타내며 이전에 통과한 저장 근거만 사용했다.

## 비용·중단 이유

시작 장부 $2.001159 → 종료 장부 **$2.056964**, 증가 **$0.055805**. 이 중 **$0.038206은 실패한 일반 Pro 요청의 사용량을 확인할 수 없어 유지한 보수적 예약액**이다. 확인된 신규 모델 토큰 비용은 $0.017599다. 장부 금액은 청구서가 아니며 기존 미확인 예약 $0.0191도 반환하지 않았다.

| 단계 | 누적 장부 | 한도 |
|---|---:|---:|
| probe | $0.001286 | $0.10 |
| development | $0.025021 | $0.25 |
| comparison | $1.327447 | $3 |
| judge | $0.703210 | $1 |
| browser | $0 | $0.15 |

예산 초과가 아닌 **실제 문맥의 구조 검증 실패** 때문에 더 큰 실험을 시작하지 않았다. Batch는 모두 정산 완료했으며 새 미완료 Batch는 없다. 예산 자동 중단 장치는 변경하지 않았다.

## 확인된 한계와 다음 단계

`model_assessment`는 파싱 오류·빈 parsed 결과·MAX_TOKENS를 같은 ValueError로 처리한다. 실제 재생의 저장 기록은 controller_error만 남아 세 원인 중 어느 것인지 확정할 수 없다. 512토큰 한도에서 발췌 목록이 추가된 구조의 안정성은 아직 확인되지 않았다. 토큰 한도를 올리거나 모델을 바꿔 반복 호출하지 않았다.

다음에는 유료 호출 전에 오류 유형·finish_reason·usage를 구분해 저장하는 오프라인 회귀를 보강해야 한다. 이후 단 한 건의 실패 사례 진단으로 원인을 확인하고, 통과한 최종 후보만 실제 검색 100건씩 비교한다. 기존 100쌍 결과 85%→83%는 변경하지 않았고, 새 후보 개선 성공이나 운영 적용을 주장하지 않는다.

일반 API의 한도와 별개로 Batch가 별도 한도를 갖는 것은 [공식 rate limits 문서](https://ai.google.dev/gemini-api/docs/rate-limits#batch-api-rate-limits)에서 확인했다. [공식 Batch API](https://ai.google.dev/gemini-api/docs/batch-api)는 비긴급 평가에 적합하며 결과 수집 뒤 실제 사용량을 정산했다. 이번 Batch는 첫 성공한 개발 답변만 채점했고 실패 요청을 반복 제출하지 않았다.

원시 결과: `schema-probe.json`, `development.json`, `failure-replay.json`, `reuse-audit.json`, `budget-audit.json`, `batch-grading/`. 재현용 실행 파일은 `*-executed.py.txt`로 보존한다. 이 결과는 코드 결함을 해결했다는 증거가 아니며, 추가 호출 중단 판단의 기록이다.
