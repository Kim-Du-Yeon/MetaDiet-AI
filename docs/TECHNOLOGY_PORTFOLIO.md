- Docling native 오류는 로그를 통해 분리·격리하고 복구 경로를 실험했다. 최종 선택은 표 표현만이 아니라 처리 안정성과 검색 품질을 함께 고려했다.
- FlashRank를 포함한 API·BM25·Kiwi·모델 런타임 조합이 1GiB Pod 예산을 초과했다. 품질 개선도 없어 리랭커를 제거했다. Kubernetes 자체 결함으로 설명하지 않는다.
- 모든 요청에 RAG와 전문 Agent 위임을 강제하면 비용·지연이 증가한다. 일반 추천은 확인된 기록으로 답하고 근거가 필요한 상담은 검색 가능한 경로로 처리한다. 실제 사용된 문서만 출처로 표시한다. [질문·실행 단계·출처 원본 캡처](food_catalog/selective-rag-20261019/README.md)
- 모델 라우팅은 새로운 모델을 모든 작업에 적용하지 않고 검증한 작업에만 제한 적용했다. 프롬프트 v1을 고정해 모델 변경 효과와 프롬프트 변경 효과를 섞지 않았다. [프롬프트 버저닝 범위](prompt_versioning/README.md)
